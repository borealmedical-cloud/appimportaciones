# Utilizamos cache para que la app no lea el archivo desde cero con cada clic, mejorando la velocidad
@st.cache_data
def cargar_datos():
    # 'dtype=str' asegura que números de guía largos como '000123' no pierdan los ceros

Para sortear esto y mantener una infraestructura de primer nivel manteniendo los costos operativos exactamente en cero dólares (0$) mientras la empresa continúa estabilizando sus ingresos, implementaremos una *Arquitectura Híbrida*:

  *

    *Tu cPanel* funcionará como la "base de datos en vivo" y mostrará la interfaz web oficial.

  *

    *Streamlit Cloud (Gratis)* funcionará como el "motor" invisible que procesa el código.

      Alternativas Gratuitas y más eficientes que un servidor

Si el objetivo es que tu equipo pueda actualizar el Excel rápidamente (y sin generar costos adicionales de servidores privados), puedes alojar el Excel en plataformas gratuitas que generan enlaces directos.

Aquí te explico las dos opciones más utilizadas en la industria para este tipo de apps:


        1. Usar Dropbox (Recomendado por su facilidad)

Puedes guardar tu Excel en una carpeta pública de Dropbox. Cuando lo edites en tu computadora, Dropbox lo sincroniza automáticamente.

  *

    Obtienes el enlace para compartir, que suele verse así: |[https://www.dropbox.com/s/codigo/STATUS_2026_FINAL.xlsx?dl=0](https://www.dropbox.com/s/codigo/STATUS_2026_FINAL.xlsx?dl=0)|

  *

    Para que la app lo lea directamente, solo debes cambiar el |?dl=0| del final por |?dl=1|.

  *

    Ese enlace con |?dl=1| es el que pones en la variable |url_excel|.


        2. Usar Google Drive

Sube tu archivo de Excel a Google Drive y ponlo en "Cualquier persona con el enlace puede leer".

  *

    Drive te dará un enlace como este: |[https://drive.google.com/file/d/ID_DEL_ARCHIVO/view?usp=sharing](https://drive.google.com/file/d/ID_DEL_ARCHIVO/view?usp=sharing)|

  *

    Copias el |ID_DEL_ARCHIVO|.

  *

    Armas tu enlace directo usando esta estructura: |[https://drive.google.com/uc?export=download&id=ID_DEL_ARCHIVO](https://drive.google.com/uc?export=download&id=ID_DEL_ARCHIVO)| y ese es el que pones en el código.

*Regla de oro:* Sin importar qué servidor o nube uses, el enlace debe ser de *descarga directa* (que al pegarlo en el navegador baje el archivo inmediatamente), no un enlace que abra una página web para ver el documento.
